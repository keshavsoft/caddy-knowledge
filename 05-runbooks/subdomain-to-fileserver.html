Operator Runbook: Promoting call.keshavsoft.com

Step-by-step instructions to take call.keshavsoft.com from an unconfigured state or smoke probe to an active, production-grade static file server at /usr/share/call.keshavsoft.com.

🔍 Pre-Flight: Inspect Current Caddy State

Check the status of call.keshavsoft.com in the live Caddy configuration: 

npx caddy-cli -d call.keshavsoft.com

⚡ The Fast Path: 1-Step Atomic Promotion

Execute the automated initialization command: 

npx caddy-fileserver init call.keshavsoft.com

This single command automatically:

  1. Provisions the directory /usr/share/call.keshavsoft.com.
  2. Generates a clean starter index.html.
  3. Creates an atomic backup /etc/caddy/caddy.json.bak.<timestamp>.
  4. Injects the Caddy JSON route block: 
    {
  "match": [{ "host": ["call.keshavsoft.com"] }],
  "handle": [
    { "handler": "vars", "root": "/usr/share/call.keshavsoft.com" },
    { "handler": "file_server", "hide": [".git"] }
  ],
  "terminal": true
}
  5. Executes caddy reload --config /etc/caddy/caddy.json in memory without dropping existing WebSockets.

✅ Post-Flight Verification

Audit that the disk folder and route are fully synchronized: 

npx caddy-fileserver check call.keshavsoft.com

Test the public HTTPS endpoint: 

curl -I https://call.keshavsoft.com
Expected Output:
HTTP/2 200 OK
server: Caddy
content-type: text/html; charset=utf-8
