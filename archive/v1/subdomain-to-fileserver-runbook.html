2
The Execution: Establish the File Server

To turn this domain into a production static site, execute this single atomic command on your VPS:

npx caddy-fileserver init call.keshavsoft.com

⚡ What This Command Automatically Executes in 2 Seconds:

  • Ubuntu Filesystem: Creates directory /usr/share/call.keshavsoft.com/
  • Starter Assets: Generates and writes responsive starter index.html & sitemap.xml
  • Caddy Ingress Route: Injects Caddy handlers vars.root and file_server into /etc/caddy/caddy.json
  • Automatic Backup: Retains snapshot /etc/caddy/caddy.json.bak.<timestamp> for rollback
  • Hot-Reload: Executes caddy reload --config /etc/caddy/caddy.json (zero connection drops)
  • Live HTTPS Verification: Probes https://call.keshavsoft.com and confirms HTTP 200 OK
