🧩 Caddy’s Core Module Pipeline

Every incoming request on the KeshavSoft VPS fleet flows through this hierarchy:

1. Listener (:443) — Terminates TLS via Automatic HTTPS certificate manager
↓
2. Route Matching — Matches request against match.host: ["subdomain.keshavsoft.com"]
↓
3. Subroute Execution — Evaluates path-specific matchers (e.g. /ws* vs *)
↓
4. Handler Execution — Dispatches to one of three handlers:
• reverse_proxy → dials upstream port (e.g. localhost:3000)
• file_server → serves static assets from vars.root
• static_response → returns in-memory HTTP 200 OK (smoke probe)
