Static File Server & vars.root Handler

How Caddy serves static assets directly from disk using kernel-level zero-copy transfers, and how the vars.root directive couples to the Ubuntu filesystem.

Official Upstream Reference: Upstream documentation on Caddy's file_server handler.
caddyserver.com/docs/modules/http.handlers.file_server ↗

⚡ High-Performance Zero-Copy Static Serving

For documentation portals, static marketing sites, and Single Page Applications (SPAs), running a Node.js process (e.g. Express with express.static) consumes unnecessary RAM and introduces memory leak risks.

Caddy's native file_server handler leverages Go's highly optimized sendfile(2) syscall. Files are streamed directly from the Linux filesystem cache into network buffers with zero intermediate memory copying.

🧩 Anatomy of a Caddy JSON Static Route

In native Caddy JSON, static file serving is implemented via a two-stage handler chain: 

{
  "match": [
    {
      "host": [
        "cli.keshavsoft.com"
      ]
    }
  ],
  "handle": [
    {
      "handler": "vars",
      "root": "/usr/share/caddy/cli"
    },
    {
      "handler": "file_server",
      "hide": [
        ".git"
      ]
    }
  ],
  "terminal": true
}
Handler 1

vars.root

Sets the context variable {http.vars.root} for all downstream handlers in this request pipeline. This binds the request to an absolute Ubuntu filesystem path like /usr/share/<domain>.

Handler 2

file_server

Sanitizes the URL path, resolves the file against root, negotiates compression (gzip/zstd), handles ETags and If-None-Match headers for 304 caching, and streams bytes to the browser.

📁 The KeshavSoft Ubuntu Directory Convention

To prevent random directory placement across VPS disks, KeshavSoft enforces a standard directory convention:

Subdomain Canonical Ubuntu Filesystem Root Role
call.keshavsoft.com /usr/share/call.keshavsoft.com Live calling display SPA / static documentation
cli.keshavsoft.com /usr/share/caddy/cli Static documentation portal
caddy.keshavsoft.com /usr/share/caddy.keshavsoft.com Ecosystem portal build files
Automated by caddy-fileserver
You never have to manually run mkdir, write HTML templates, and edit JSON routes by hand. Running npx caddy-fileserver init call.keshavsoft.com handles this entire 5-step lifecycle in one command.
