caddy-subdomain: Two-Stage Verification & Smoke Probes

The Subdomain Lifecycle Engine: Eliminates connection guesswork by testing DNS and SSL with zero-dependency smoke probes before touching backend application code or ports.

Official Package & Repository: Published on npm and GitHub with full CLI & ESM library support.
npm: caddy-subdomain ↗ • github.com/keshavsoft/caddy-subdomain ↗

🧭 The Problem It Solves

When configuring a new subdomain (e.g. call.keshavsoft.com), developers frequently configure DNS, Node.js ports, Caddy reverse proxies, and systemd services simultaneously. When the browser throws a connection error, it is impossible to know what failed:

  • Did GoDaddy DNS not propagate yet?
  • Did Let's Encrypt hit an ACME challenge timeout?
  • Did Node.js crash or fail to bind port 5000?
  • Is there an Ubuntu firewall or port collision issue?

⚡ The Two-Stage Solution

Level 1: The Smoke Test Probe (Zero Dependencies)

Zero Code / Zero Port

Injects an in-memory static_response handler into Caddy JSON returning HTTP 200 OK: 

npx caddy-subdomain probe call.keshavsoft.com

Visit https://call.keshavsoft.com. If you see the green padlock and "200 OK", DNS and SSL are 100% verified. Node.js wasn't even touched!

Level 2: Promote to Reverse Proxy

Live Production

Now that DNS and TLS are proven live, promote the route to dial your Node.js port: 

npx caddy-subdomain add call.keshavsoft.com 5000

Replaces the probe with reverse_proxy dialing localhost:5000. Existing SSL certificates remain active without re-negotiation.

📋 Command Reference

Command Role
caddy-subdomain probe <domain> Injects 200 OK smoke probe, reloads Caddy, and probes live HTTPS endpoint.
caddy-subdomain add <domain> <port> Promotes domain to reverse proxy dialing internal port.
caddy-subdomain static <domain> <root> Configures native file_server with vars.root document root.
caddy-subdomain check <domain> Inspects domain presence in Caddy JSON and reports active handler type.
caddy-subdomain list Lists all subdomains managed by Caddy.
