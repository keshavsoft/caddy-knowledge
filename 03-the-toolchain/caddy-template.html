caddy-template: Battle-Tested Route Blueprints

The Route Blueprint Engine: Emits pristine, schema-compliant Caddy JSON route blocks for reverse proxies, WebSockets, static file servers, and multi-domain aliases.

Official Package & Repository: Published on npm and GitHub with live browser generator.
npm: caddy-template ↗ • github.com/keshavsoft/caddy-template ↗

📐 The 4 Canonical Blueprints

1. proxy

Unified Port

Standard reverse proxy for Node.js, Express, Go, or Python. Transparently tunnels WebSocket upgrades. 

npx caddy-template proxy appointment.keshavsoft.com 3000

2. ws-split

Split Daemons

Routes /ws* path requests to a dedicated WebSocket port (8080) and all other traffic to an API server (9011). 

npx caddy-template ws-split quotation.keshavsoft.com 9011 8080

3. static

Direct Disk

High-performance static file serving via vars.root and native file_server. 

npx caddy-template static cli.keshavsoft.com /usr/share/caddy/cli

4. multi-host

Aliases

Binds apex domain and www subdomain to a single upstream target with automatic multi-cert issuance. 

npx caddy-template multi-host keshavsoft.com,www.keshavsoft.com 9328

💻 Programmatic Node.js ESM Usage

In addition to the CLI, caddy-template exports pure JavaScript functions for integration into automation pipelines: 

import { proxy, wsSplit, staticServer } from "caddy-template";

// Generate a pristine AST object:
const routeAST = proxy("appointment.keshavsoft.com", 3000);

console.log(JSON.stringify(routeAST, null, 2));
